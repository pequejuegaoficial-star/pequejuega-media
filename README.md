# pequejuega-media

Medios y herramientas de Peque Juega (@pequejuega.oficial).

| Carpeta | Qué hay |
|---|---|
| `reels/` | Vídeos publicados o programados, `AAAA-MM-DD-tema.mp4` (fecha de publicación). Hasta el 10-nov-2026 son de diapositivas fijas; desde el 12-nov, animados. Dos archivos antiguos llevan la fecha de creación y no la de publicación: `2026-11-09-manualidad-prismaticos.mp4` (salió el 10-nov) y `2026-11-10-ruta-parque.mp4` (versión fija, sustituida por `2026-11-12-ruta-parque.mp4`). |
| `tools/animado/` | Motor de reels animados, biblioteca de dibujos, iconos y fichas. Ver su README. |
| `tools/comprobar-pagina.js` | Comprueba en local la página de enlaces. |
| `tools/musica.py` | Genera música original. |
| `tools/plantilla-reel.js`, `tools/cierre-libro.js` | Plantilla antigua de diapositivas fijas. Solo de reserva. |
| `music/` | Pistas originales. |
| `docs/` | Página de enlaces (GitHub Pages): https://pequejuegaoficial-star.github.io/pequejuega-media/ |
| `embudo/` | Textos fijos del embudo LIBRO. |

Repositorio público: no subir claves, datos personales ni el código de los libros.

TikTok a mano

  1. Pulsa «Descargar vídeo» (se guarda en el móvil).
  2. Pulsa «Copiar texto».
  3. Abre TikTok → + → Cargar → elige el vídeo → pega el texto → Publicar.
  4. Quédate 5–10 minutos usando la app después de publicar.
